## HSET / HSETNX

```bash
HSET key field value [field value ...]
HSETNX key field value     # set only if field doesn't exist
```

## HGET / HMGET / HGETALL

```bash
HGET user:1 name
HMGET user:1 name email role
HGETALL user:1
```

## HDEL / HEXISTS / HLEN

```bash
HDEL user:1 role
HEXISTS user:1 email       # 1 or 0
HLEN user:1
```

## HKEYS / HVALS

```bash
HKEYS user:1
HVALS user:1
```

## HINCRBY / HINCRBYFLOAT

```bash
HINCRBY product:1 stock -1
HINCRBYFLOAT product:1 price 0.50
```

## HRANDFIELD

Return random fields:

```bash
HRANDFIELD key             # one random field
HRANDFIELD key 3           # 3 unique fields
HRANDFIELD key -5          # 5 fields (may repeat)
HRANDFIELD key 3 WITHVALUES
```

## HSCAN

Cursor-based iteration over hash fields:

```bash
HSCAN key 0
HSCAN key 0 MATCH "prefix:*" COUNT 100
```
