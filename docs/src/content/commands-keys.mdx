## DEL / UNLINK / EXISTS

```bash
DEL key [key ...]
UNLINK key [key ...]
EXISTS key [key ...]
```

## EXPIRE / PEXPIRE / EXPIREAT

```bash
EXPIRE key 60
PEXPIRE key 5000
EXPIREAT key 1700000000
```

## EXPIRETIME / PEXPIRETIME

```bash
EXPIRETIME key             # absolute expiry in seconds (-1 = no expiry, -2 = missing)
PEXPIRETIME key            # absolute expiry in milliseconds
```

## TTL / PTTL / PERSIST

```bash
TTL key
PTTL key
PERSIST key
```

## RENAME / RENAMENX / COPY

```bash
RENAME old new
RENAMENX old new
COPY src dst [REPLACE]
```

## TYPE / TOUCH / RANDOMKEY

```bash
TYPE key
TOUCH key [key ...]
RANDOMKEY
```

## KEYS / SCAN

```bash
KEYS *
KEYS user:*
SCAN 0 MATCH user:* COUNT 100
```

## SORT

```bash
SORT key
SORT key DESC LIMIT 0 10
SORT key ALPHA
SORT key STORE dest
```

## OBJECT

```bash
OBJECT ENCODING key
OBJECT REFCOUNT key
OBJECT IDLETIME key
```
