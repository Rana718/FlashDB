## SET

```
SET key value [EX seconds] [PX milliseconds] [NX] [XX] [GET]
```

| Option  | Effect                              |
| ------- | ----------------------------------- |
| `EX s`  | Set TTL in seconds                  |
| `PX ms` | Set TTL in milliseconds             |
| `NX`    | Only set if key does not exist      |
| `XX`    | Only set if key already exists      |
| `GET`   | Return the old value before setting |

```bash
SET user:1 "rana"
SET cache:item "data" EX 60
SET lock:resource "owner" NX
SET counter "10" XX GET
```

## GET / GETDEL / GETSET / GETEX

```bash
GET key
GETDEL key                 # get and delete atomically
GETSET key "new"           # get old, set new
GETEX key EX 3600          # get and update TTL
GETEX key PERSIST          # get and remove TTL
```

## MSET / MGET / MSETNX

```bash
MSET key1 val1 key2 val2
MGET key1 key2
MSETNX k1 v1 k2 v2        # set all or none
```

## INCR / DECR

```bash
INCR counter
DECR counter
INCRBY counter 10
DECRBY counter 5
INCRBYFLOAT price 1.50
```

## APPEND / STRLEN

```bash
APPEND key " world"
STRLEN key
```

## GETRANGE / SETRANGE / SUBSTR

```bash
GETRANGE key 0 4
SETRANGE key 6 "rust"
SUBSTR key 0 4             # alias for GETRANGE
```

## SETNX / SETEX / PSETEX

```bash
SETNX key value
SETEX key 60 value
PSETEX key 5000 value
```

## LCS

Longest Common Substring between two keys:

```bash
LCS key1 key2
LCS key1 key2 LEN          # length only
```
